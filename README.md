# CalculaEnergía

Calculadoras de energía gratuitas para España: https://calculaenergia.github.io/

- `index.html`: placas solares (ahorro y amortización)
- `factura-luz.html`: simulador de factura PVPC
- `consumo-electrodomesticos.html`: consumo por aparato
- `potencia-contratada.html`: potencia necesaria y ahorro
- `coste-carga-coche-electrico.html`: eléctrico vs gasolina/diésel

Sitio estático servido con GitHub Pages. Generado con `energia.py` (sitegen).
Mantenimiento: precio medio PVPC y carburantes (mensual), peajes de potencia (anual).
